# SC4024 Data Visualization

The objective of this project is to give an understanding of how the world population has shifted over time and how it is projected to be in the coming years. This project will also briefly touch on how the population of each continent changed over time and which ones will lead the newer generations. The main message of the presentation is that change has already occurred and although it may feel alarming at first, it is more about what we can do to support this new change rather than what we should do to prevent it.
